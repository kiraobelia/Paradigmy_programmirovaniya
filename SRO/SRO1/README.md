# Мини-проект: Система бронирования отеля

**Автор:** Керимбаева Карина, ТИИ-25-21  
**Дисциплина:** Парадигмы программирования  
**Вариант:** 5 (Адаптирован под бронирование отеля)

## Описание проекта
Программа предназначена для управления бронированием номеров отеля с учетом категории номеров (Люкс, Семейный, Стандарт), типов питания (Завтрак, 3-разовое), корпуса (Центральный, Боковой), видов из окна (На озеро, На улицу, Во двор) и типов кроватей (Раздельные, Совместные).

## Архитектура и темы лекций 1–8
- **Лекция 1:** Сравнение императивного и функционального подходов поиска в `main.py`.
- **Лекция 2:** Императивный прототип в `main.py`.
- **Лекция 3:** Процедурная декомпозиция (6 основных функций в `logic.py`).
- **Лекция 4:** Модульная организация (`models.py`, `logic.py`, `main.py`).
- **Лекция 5:** ООП модели (`Room`, `Booking`) с инкапсулированными свойствами.
- **Лекция 6:** Полиморфизм и композиция политик (`BaseAvailabilityPolicy`, `RoomFeaturePolicy`, `DateAvailabilityPolicy`, `CompositeBookingChecker`).
- **Лекция 7:** Чистые функции, отсутствие боковых эффектов, рекурсивный поиск дат.
- **Лекция 8:** Использование `map`, `filter`, `reduce` и замыканий (`make_discount_calculator`).
